# AlgoFlow — Hot 100 算法可视化学习平台

一个本地优先的算法学习工作台。通过真实输入生成可回放的执行轨迹，同时展示数据结构、变量、代码行和中文解释。

> 当前版本：官方 Hot 100 的 **100 题索引、17 个专题全部收录，14 道真实算法演示已实现**。其余 86 题的动画和完整题解待实现，页面有明确标记。本版本不是 100 道动画全部完成版。

## 启动

建议使用 Node.js 22.12+（本次在 Node.js 26 下验证）。不需要后端、数据库或 API Key。

```bash
npm install
npm run dev
```

打开终端显示的 Local 地址，默认是 http://127.0.0.1:5173/ 。

```bash
npm test          # 自动化测试
npm run build    # TypeScript 检查与生产构建，输出到 dist/
npm run preview  # 本地预览生产构建
```

可将 `dist/` 部署到任何静态网站托管服务。路由采用 `#/problem/题号`，无需服务器重写规则。已配置 GitHub Pages 自动构建与部署，发布步骤见下文。

## 发布到 GitHub Pages

网站为纯静态前端，访问者不需要安装 Node.js。每个人的学习进度和笔记保存在自己的浏览器，不会上传到仓库或与其他人共享。

1. 在 GitHub 创建仓库（免费个人账号通常使用公开仓库），将本项目源码推送到 `main` 分支。
2. 进入仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
3. 进入 **Actions → Test and deploy GitHub Pages**，等待工作流完成；如果设置 Pages 前已经推送过代码，可点击 **Run workflow** 重新执行。
4. 成功后在工作流的 `github-pages` 部署环境中打开网站网址。普通项目仓库的地址格式是 `https://你的用户名.github.io/仓库名/`。

工作流使用 Node.js 24，先执行 `npm ci`、算法测试、构建和资源路径检查，成功后才发布 `dist/`。以后推送到 `main` 会自动更新网站。`vite.config.ts` 使用相对资源路径，兼容仓库子目录；哈希题目路由支持刷新和分享。

只提交源码和锁文件，不提交 `node_modules/`、`dist/`、`work/`、`outputs/` 或本地环境文件。仓库公开后，源码可被其他人查看；当前没有额外授予开源许可证。

如果已有其他 GitHub Pages 网站，应使用单独的项目仓库，避免覆盖原来的用户主页仓库。仓库和 Pages 的创建 / 启用需要你的 GitHub 账号授权。本地配置完成不代表远端已经发布，是否上线以 Actions 的部署结果为准。

## 交互功能

- 三栏学习工作台；窄屏折叠导航抽屉，代码移到演示下方。
- 17 个专题的展开收起；按题号、中文名称或英文 slug 搜索；难度筛选；仅显示可演示题目。
- 每题独立哈希路由，支持刷新、直接链接和浏览器前进后退。
- 播放、暂停、重置、前进一步、后退一步、任意进度跳转；0.25 / 0.5 / 1 / 1.5 / 2 / 3 倍速即时生效。
- Python 当前行与执行状态同步；可复制代码。Java / C++ 明确标记为待实现，没有启用不准确的行映射。
- 思考模式隐藏解法、动画和代码；引导模式逐条展开提示；演示模式完整展示。
- 自定义 JSON 输入：重新执行算法生成轨迹；校验格式、数据类型、规模与题目约束；恢复默认输入。
- 未学习 / 学习中 / 已掌握 / 需要复习四种状态，专题与全局统计，localStorage 持久化。
- 进度导出 JSON、复制 JSON 和校验后导入。**导入替换全部进度**；非法文件不会修改已有进度。内嵌浏览器可能限制下载，此时可复制 JSON 自行保存。
- 每题学习笔记自动保存；**笔记不包含在进度导出中**，可自行复制备份。
- 深色 / 浅色主题持久化，代码面板折叠，专注模式。
- 快捷键：Space 播放 / 暂停，← / → 单步，Esc 退出专注模式；在输入控件、按钮或弹窗中不触发全局播放快捷键。

## 架构

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 题目数据 | `src/data/problems.ts` | 官方题号、名称、难度、分类、标签、原题链接及原创概述 |
| 算法执行 | `src/algorithms/core.ts`、`extended.ts` | 纯 TypeScript 算法和与 Python 代码对应的语义事件 |
| 状态记录 | `src/algorithms/trace.ts`、`src/types.ts` | 统一 `AlgorithmStep`、深拷贝快照、输入校验与步骤上限 |
| 可视化 | `src/components/Visualizers.tsx` | SVG 数组、指针、链表、二叉树、递归树、DP 与网格；哈希表和队列 / 栈辅助视图 |
| 代码与解释 | `src/components/CodePanel.tsx` | 语法着色、真实行映射、变量、解释与复杂度 |
| 播放器 | `src/hooks/usePlayer.ts` | 单一索引和可清理的播放定时器，完全读取轨迹 |
| 学习管理 | `src/hooks/useProgress.ts` | 状态持久化、严格导入验证、导出 |

`AlgorithmStep` 包含步骤号、执行阶段、说明、原因、代码行、数值、稳定元素身份、指针、变量、比较 / 高亮 / 成功 / 撤销元素、哈希表、队列、树节点及边、DP、路径、结果集、网格和最终结果。

算法函数不会依赖 React，不使用定时器或随机动画。播放器只改变读取的快照索引，回退不需要逆向执行算法。每条记录通过 `structuredClone` 隔离，避免后续更新污染早期状态。

展示的复杂度针对解题算法本身，不包含教学轨迹和渲染的成本。保存完整状态需要额外内存；回溯答案另占 O(n · n!) 空间。输入有规模限制，所有轨迹最多记录 6000 步；全排列最多 5 个互异数字。

## 自定义输入示例

```json
{"nums": [3, 2, 4], "target": 6}
```

两数之和应返回 `[1, 2]`。不存在配对时返回 `[]`；若有多解，返回遍历首次找到的配对。

```json
{"head": [1, 2, 3, 4, 5]}
```

链表按节点身份连接，允许重复值；`[]` 代表空链表。

```json
{"root": [3, 9, 20, null, null, 15, 7]}
```

二叉树使用紧凑层序表示：按队列消费每个非空父节点的左右孩子。`null` 表示缺失。`[1,null,2,3]` 表示 1 的右孩子为 2，2 的左孩子为 3；不是堆下标表示。上限为 31 项、5 层，孤立非空节点会被拒绝。

```json
{"s": "abcabcbb"}
```

最长子串按 Unicode 码点处理字符，不按用户感知的复杂字形簇处理。

```json
{"n": 6}
```

爬楼梯支持 1–30，结果在安全整数范围内。

```json
{"nums": [1, 2, 3]}
```

全排列要求数字互不相同。空数组对应一个空排列 `[[]]`。更长的搜索树可在画布内横向滚动，当前分支自动跟随。
